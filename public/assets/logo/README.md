# Club logo

Put the DevClub TRCAC logo in this folder as:

```
devclub-logo.png
```

A square PNG (512×512 or larger, transparent background) works best. It is rendered inside
a circular badge at 34–96 px, so keep the artwork centred and avoid fine detail.

Until the file exists, the badge falls back to the glowing cyan circle with a bulb mark, so
nothing looks broken in the meantime.
